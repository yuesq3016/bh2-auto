# ===========================================================================
#  共鸣屋 购买名单  —— 可以直接用记事本编辑,保存即生效
# ===========================================================================
#
#  规则:
#    这一行写的名字,如果刷出来【且未拥有】 -> 自动购买
#    不在这个文件里的装备,即使未拥有 -> 不买
#    名单里的装备如果【已拥有】 -> 只记录,不买
#
#  写法:
#    一行一个装备名
#    以 # 开头的行是注释,会被忽略(可以用来临时停用某一行)
#    名字用【部分匹配】,所以写短一点更保险:
#        写  玛雅      -> 能匹配 玛雅黄金翼
#        写  小蜜蜂    -> 能匹配 医疗精灵·小蜜蜂
#    行尾也可以加注释,例如:  渴求之镰    # 优先
#
#  提示:OCR 偶尔会漏字,所以名字越短越不容易失配。
#        但太短(比如只写"之")会误匹配到别的装备,建议至少 3 个字。
#
# ===========================================================================
