崩坏学园2 自动化（bh2-auto）
==============================

一个仿 MAA 的《崩坏学园2》日常自动化脚本：任务即数据、识别用模板/颜色、循环用轮询。
纯 Python 实现（tkinter 界面 + ADB 控制 + PaddleOCR），通过 ADB 操作 MuMu 模拟器里的游戏。

全程使用 DeepSeek 完成，在前人的基础上修改。本为自己使用，既然完成了索性发出来。
底子来自 MAAHG2（MIT）：https://github.com/Choi-Peng/MAAHG2


一、能做什么
------------
① 启动游戏 + 进游戏(关弹窗)       ⑦ 多元裂缝:使魔的爱 + 虚轴之庭(快捷战斗)
② 关闭弹窗(公告/维护/签到/促销)    ⑧ 清体力(BONUS)
③ 领取每日签到                    ⑨ 存在感(每日任务)
④ 收菜(使魔探险:收菜 + 派出)      ⑩ 社团领取(消息 + 社团)
⑤ 商店:领免费零时之种             ⑪ 再次清体力
⑥ 共鸣屋:刷新 + 按名单买          ⑫ 再次存在感(含每周任务)

任务按固定顺序执行（不按勾选顺序），每项开始前会自动把游戏带到需要的页面。


二、运行环境
------------
- Windows 10/11 x64
- MuMu 模拟器 12，分辨率 1280×720
- 游戏：官服（包名 com.miHoYo.HSoDv2Original），混服不管
- 免安装包：解压后双击 Simauto.exe
- 源码包：装好 Python 3.11/3.12 和依赖后，双击 启动.cmd 或 python -m simauto gui


三、第一次用
------------
1. 打开模拟器，把游戏开起来
2. 双击 Simauto.exe
3. 「设置」页确认设备地址 127.0.0.1:16384（MuMu 默认）和装备组/套装
4. 回「一键长草」页，勾任务，点「开始!」
5. 建议第一次只勾「① 启动游戏」，确认广告能自动关掉，再全选

抓不到画面时先跑一次 Simauto.exe doctor 和 Simauto.exe find（源码版：
python -m simauto doctor / find），确认 ADB 和截图后端是通的。


四、自动套开关
--------------
运行选项里有「有自动套」勾选框：

- 勾上（默认）—— 有自动套：角色自己会走位和攻击，脚本开战后只等结算。
- 取消       —— 没有自动套：进关卡（清体力 BONUS / 首通清理）后，脚本用两根手指
                 按住「向右」和「第一个装备键」，一直压到出现战斗结算再松开。

虚轴之庭、使魔的爱用的是「快捷战斗」，不进战斗画面，不受这个开关影响。
