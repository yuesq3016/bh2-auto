simauto 使用说明（Windows）
================================

解压后不需要装 Python：双击 Simauto.exe 就能用。

一、启动
--------

双击 Simauto.exe，打开图形界面。

命令行用法同理：
    Simauto.exe doctor      找模拟器、检查环境
    Simauto.exe find        自动定位窗口并试所有截图后端
    Simauto.exe grab        存一张截图
    Simauto.exe run --config configs\bh2-enter.json --dry-run

（包里也附了源码，装了 Python 3.11/3.12 的话可以直接跑：
  先双击 install-deps.cmd 装 numpy，再双击 启动.cmd 或 python -m simauto gui）

二、第一次用
------------

1. 打开安卓模拟器（实测 MuMu 模拟器 12，1280x720），把游戏开起来。
2. Simauto.exe doctor 看环境，Simauto.exe find 确认能抓到画面。
3. grab 存一张截图，确认不是黑屏。

三、模板
--------

包里的 templates/ 是 1280x720 下能用的示例。分辨率和界面差异大了就要重抠：
1. grab 存截图
2. crop 把按钮/图标抠成模板
3. match --calibrate 得到建议阈值
4. 把阈值填回 configs\*.json 的 threshold

配置是 JSONC，允许 // 注释。

四、先干跑
----------

    Simauto.exe validate --config configs\bh2-enter.json
    Simauto.exe run --config configs\bh2-enter.json --dry-run
    Simauto.exe run --config configs\bh2-enter.json
